C语言关于scanf,typedef的笔记

#关于scanf,typedef

一.scanf 是干嘛的？

scanf = 让程序等待你从键盘打字输入数字/文字，把你敲的内容存到变量里。
没有它程序只会自己跑，有了它你能手动给程序填数据。

类比：
程序是收银机，printf 是屏幕提示“请输入金额”，scanf 就是读取你按键盘输的数字。

固定格式（死记就行）0=
scanf(“格式符号”, &变量名);
两个必懂关键点：

二.格式符号：告诉程序你要输入什么类型数据

%d = 整数（年龄、数字）

%f = 小数（身高、价格）

%s = 一串文字（姓名、单词，不带空格）

& 取地址符号：除了数组，普通变量前面必须加！
大白话：& 就是告诉程序“把你输入的东西放到这个变量的内存盒子里”

最简单完整例子（输入年龄）
#include <stdio.h>
int main()
{
int age; // 造一个盒子age，装整数
printf(“请输入你的年龄：”); // 提示文字
scanf(“%d”, &age); // 等待键盘输入数字，存进age
printf(“你今年%d岁”, age); // 打印你输入的数字
return 0;
}
运行流程：

  1. 屏幕弹出：请输入你的年龄：

  2. 你键盘敲 18，按回车

  3. 18 自动装进 age 变量

  4. 屏幕输出：你今年18岁

分类型举例，一看就会

输入整数 %d
int num;
scanf(“%d”, &num);
输入小数 %f
float height;
scanf(“%f”, &height);
输入名字（字符数组，不用加&！重点）

之前结构体的 char name[20] 就是数组，数组名字本身自带地址，不许写&
char name[20];
scanf(“%s”, name); // 没有&！
三.初学者最容易踩的3个坑

坑1：普通变量忘记写 &

错误：scanf(“%d”, age);
正确：scanf(“%d”, &age);
不写&程序会直接崩溃乱码。

坑2：给文字数组多加了&

错误：scanf(“%s”, &name);
正确：scanf(“%s”, name);
数组自带地址，加&反而报错。

坑3：输入带空格的文字读不全

scanf(“%s”) 遇到空格就停止读取
比如你输入 zheng jiawei，它只会存 zhang，后面文字直接丢掉。

四.typedef到底是干嘛的？

直译：类型重命名
大白话：给复杂的数据类型起一个简短好写的外号，少打字、不容易写错。

对比不用typedef 和 用typedef 的区别（拿结构体举例）

1.不使用typedef（原生写法，每次都要写struct）
struct Student{
char name[20];
int age;
};
// 创建变量必须完整写 struct Student
struct Student s1;
struct Student s2;
缺点：每次新建学生变量，都要带上 struct 四个字，代码长、麻烦。

2.使用typedef（起外号 Stu）
// typedef + 原类型 + 新外号
typedef struct Student{
char name[20];
int age;
} Stu;
// 直接用外号创建变量，不用写struct
Stu s1;
Stu s2;
拆解这句：
typedef struct Student = 原来完整的类型名
Stu = 我们给它起的简短外号

3.通用万能公式（所有类型都能用typedef）
typedef 原来的类型 新名字;
示例1：给int起外号（简单类型也能用）
typedef int Num;
Num a = 18; // 等价于 int a = 18;
示例2：给float起外号
typedef float Score;
Score math = 95.5;
4.初学者最容易记混的关键点

5.typedef 不会创造新类型，只是换个名字，底层还是原来的struct/int/float；

62.结构体搭配typedef是写代码最常用场景，专门简化变量定义；

7.顺序不能写反：typedef 原名 外号，不能反过来。

五.scanf与typedef和之前结构体结合的完整实操代码
#include <stdio.h>
#include <string.h>

typedef struct Student{
char name[20];
int age;
} Stu;

int main()
{
Stu s1;
// 输入姓名
printf(“请输入学生姓名：”);
scanf(“%s”, s1.name);
// 输入年龄
printf(“请输入学生年龄：”);
scanf(“%d”, &s1.age);
// 打印读取到的数据
printf(“学生：%s，年龄：%d”, s1.name, s1.age);
return 0;
}
运行后你手动输入名字、年龄，程序就能读取并存进结构体里。

极简总结

  1. scanf 用来读取键盘输入；

  2. 数字/小数变量前面必须加 &；

  3. char 文字数组不用加 &；

  4. %d存整数，%f存小数，%s存文字。
