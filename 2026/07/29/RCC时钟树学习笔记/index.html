RCC时钟树学习笔记

STM32F407 RCC+时钟树
一、基础概念

  1. RCC全称：复位和时钟控制器（Reset & Clock Control）
    作用：掌管芯片所有时钟开启、频率升降、总线分频、外设时钟开关，相当于整个单片机的总电源+调速开关；所有外设（GPIO、定时器、串口）必须开启时钟才能工作
  2. 时钟树：时钟从源头出发，经过分频、倍频、逐级分流，流向CPU、各类总线、外设的完整流向结构图

二、5个原始时钟源头（所有频率的根基）
高速时钟（给CPU、主系统用）

  1. HSI：内部高速RC时钟（16MHz）
    上电默认时钟，芯片内部自带，不用外接晶振；缺点：精度差、温漂大
    上电瞬间单片机先跑这个低速时钟，执行时钟初始化代码，切换到高精度HSE/PLL
  2. HSE：外部高速晶振（标配8MHz）(范围4-26MHz)
    开发板焊接外部石英晶振，精度极高、稳定；配置168MHz主频唯一首选源头
    低速时钟（仅低功耗计时器件使用）
  3. LSE：外部32.768KHz晶振
    专门给RTC实时时钟提供基准，断电靠纽扣电池走时间
  4. LSI：内部低速RC时钟（32KHz）
    精度差，只给独立看门狗、待机唤醒使用
  5. 双PLL锁相环（频率倍增核心模块）
    • 主PLL（PLL）：你一直在配置的模块，把25MHz低频晶振拉升成168MHz高频系统时钟，同时分出48MHz固定时钟供给USB（必须严格48MHz才能识别U盘）
    计算公式：SYSCLK = (HSE ÷ M) × N ÷ P
    经典参数：M=25、N=336、P=2 → (8/8)*336/2 = 168MHz；Q=7专门算出48MHz给USB
    • PLLI2S：音频专用锁相环，播放音乐用，日常点灯几乎用不到

三、时钟主干完整流向
HSE(25MHz) → PLL分频倍频 → SYSCLK(168MHz系统总时钟) → 分成3路总线时钟

  1. SYSCLK：系统总时钟（最高168MHz）
    整个芯片最高频率时钟，供给内核CPU、Flash存储器；可三选一来源：HSI / HSE / PLL输出（我们固定选PLL）
  2. 三级总线分频（RCC->CFGR寄存器配置）
    SYSCLK向下分频，分出3条马路，不同外设分配不同速度，兼顾性能+省电：
  3. HCLK（AHB总线时钟）
    默认不分频：HCLK = SYSCLK = 168MHz
    承载：CPU内核、DMA内存搬运、Flash、高速存储器、以太网等核心硬件，主干道全速跑
  4. PCLK2（APB2高速外设总线）
    二分频：PCLK2 = HCLK ÷ 2 = 84MHz
    承载：GPIO所有引脚、ADC、高级定时器、串口1等高速外设（LED引脚挂载在这里）
    规则：APB2最大上限84MHz。
  5. PCLK1（APB1低速外设总线）
    四分频：PCLK1 = HCLK ÷ 4 = 42MHz
    承载：普通串口、I2C、基础定时器、看门狗等低速外设；上限最高42MHz。
    补充规则：如果APB总线分频系数≥2，挂载上面的定时器时钟会自动翻倍，方便定时计算
    四、外设时钟开关逻辑
    每条总线下面挂载一堆外设，默认全部关闭时钟，必须通过RCC寄存器手动开启对应外设时钟，硬件才会通电工作：
    例：开启GPIOA引脚时钟：RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;
    不开这句，LED引脚初始化完全无效，灯不会亮

五、配套关键硬件设置（代码里的FLASH等待周期）
CPU高速读取Flash里的程序时，Flash硬件速度跟不上168MHz主频，需要设置等待周期（LATENCY）：
• 168MHz：必须配置5个等待周期
• 主频降低，等待周期同步减小，否则程序运行时序错乱、延时无变化

六、上电完整启动流程（对应你的SetSysClock函数执行步骤）

  1. 上电默认跑HSI内部16MHz低速时钟；
  2. 开启外部HSE 25MHz晶振，等待晶振震荡稳定；
  3. 配置PLL的M/N/P/Q参数，算出168MHz主频+48MHz USB时钟；
  4. 开启PLL，等待PLL倍频稳定就绪；
  5. 设置Flash读写等待周期，适配当前主频；
  6. 将系统时钟SYSCLK切换为PLL输出的168MHz；
  7. 配置AHB、APB1、APB2总线分频比例；
  8. 后续main函数里开启GPIO时钟、初始化引脚、点灯循环

七、MCO是什么
MCO = 单片机时钟输出引脚
芯片预留了专门引脚，可以把芯片内部看不见的各种时钟信号引到芯片外面

八、输出监控系统时钟，拆开含义

  1. 系统时钟（SYSCLK）：就是你用PLL配置的168MHz总主频，CPU运行的基准时钟，封在芯片内部，肉眼、万用表都测不到；
  2. 输出：把SYSCLK信号接到MCO引脚上；
  3. 监控：拿示波器接这个引脚，查看波形频率。
  4. 作用（你现在最需要的）
    一次次修改PLL的N数值、调整主频，心里没法确认：
    单片机到底有没有真正跑到 168M / 84M？
    PLL有没有锁定成功？时钟配置写错有没有乱频？
    开启MCO输出SYSCLK之后：
    示波器测出多少赫兹，就代表当前单片机实际主频是多少，用来验证你的时钟代码是否正确

九、F407实操细节

  1. 选用 MCO2（PC9引脚），专门可以输出SYSCLK系统主时钟；
  2. 注意限制：GPIO引脚最高承受100Mhz信号，168MHz超出上限，必须内部二分频输出；
  3. 举例：
    168MHz二分频输出 → 引脚测出来84MHz波形，就证明系统时钟确实是168MHz，配置无误
