C语言运算知识

一.原码，反码，补码
电脑/单片机只认识二进制 0 和 1，数字分正数、负数，机器靠最高一位区分正负：
最高位=0 → 正数
最高位=1 → 负数
我们拿1字节（8位二进制）举例，好理解。

  1. 原码：给人看得懂的写法
    规则：
    最高位符号位，后面正常写数字二进制。
    举例8位：
    +5：00000101 （0代表正数）
    -5：10000101 （1代表负数）
    缺点：
    0有两种写法：00000000（+0）、10000000（-0），重复浪费空间
    计算机做减法巨麻烦，硬件不好计算，所以机器不用原码运算

  2. 反码：过渡产物，只为算补码用
    规则：
    正数：反码 = 原码（不变）
    负数：符号位不动，剩下所有0变1、1变0
    还用8位举例：
    +5 原码：00000101 → 反码不变：00000101
    -5 原码：10000101 → 符号1不动，后面取反 → 11111010
    缺点：
    0还是有两个表示，依旧不能直接拿来做减法，只是中间步骤。
    3=（-2）= 00000011+11111101=1 000000000（多一位）

  3. 补码：计算机真正存数字、算数字的格式（重点！）
    规则
    正数：补码 = 原码 = 反码，全程不变
    负数：负数反码 + 1 = 补码
    举例 -5
    原码：10000101
    反码：11111010
    反码+1 → 补码：11111011

为什么一定要用补码？两大好处
解决0重复问题，8位二进制只有一个0：00000000
举个例子：计算 5 - 3 = 5 + (-3)
5补码：00000101
-3补码：11111101
两者相加：00000010 也就是2，计算正确！

极简记忆口诀
原码：人看的，正负分开写
反码：负数符号不动，其余全部翻转
补码：正数原样，负数反码加1；电脑存数字、算加减全靠它因此计算机内部用补码=

二.位运算与位运算符
单片机、电脑里所有数字底层都是二进制0、1
位运算 = 直接操作整数类型的二进制里每一个0和1，嵌入式写寄存器、控制引脚

位运算符有6个

  1. 按位与 & （符号：和）
    规则：两位同时为1，结果才是1；只要有一个0，结果就是0
    口诀：全1才1，有0则0
    例：3 & 1
    3二进制：00000011
    1二进制：00000001
    结果：00000001 = 1
    嵌入式用途：清零某一位、读取寄存器某一个引脚状态

  2. 按位或 | （符号：竖线）
    规则：任意一位是1，结果就是1；全0才是0
    口诀：有1则1，全0才0
    例：3 | 1
    00000011 | 00000001 = 00000011 =3
    嵌入式用途：把指定某一位置1（拉高引脚电平）

  3. 按位异或 ^
    规则：两位不一样=1，两位相同=0
    口诀：相同出0，不同出1
    例：3 ^ 1
    00000011 ^ 00000001 = 00000010 =2
    用途：翻转指定二进制位、简单加密、交换数字不用第三方变量

  4. 按位取反 ~ （单目运算符，只写在数字前面）
    规则：所有0变1，所有1变0，符号位也一起翻转
    例：char a=3（00000011）
    ~a 全部翻转 = 11111100
    重点：单片机char是有符号数，最高位1代表负数，取反后会变成负数。
    用途：批量清零多位寄存器

  5. 按位左移 <<
    格式：数字 << 移动位数
    规则：二进制整体往左挤，右边空出来补0，左边挤出去的数字直接丢掉
    例：1 << 2
    1：00000001
    左移2位：00000100 等于4
    隐藏技巧：左移n位 = 数字 × 2的n次方

  6. 按位右移 >>
    格式：数字 >> 移动位数
    分两种情况：

  7. 正数：整体右挤，左边补0

  8. 负数（补码存储）：整体右挤，左边补1
    例：4 >> 1
    4：00000100 → 右移1位 00000010 =2
    —4 >> 1
    —4：11111100 → 右移1位 11111110 =—2
    隐藏技巧：右移n位 = 数字 ÷ 2的n次方（取整数）

嵌入式最常用组合操作（写寄存器必用）

  1. 某一位置1：a |= (1<<n)
  2. 某一位清零：a &= ~(1<<n)
  3. 翻转某一位：a ^= (1<<n)
    总结
  4. & 留1清0；| 统一置1；^ 相同归零
  5. ~ 全部翻转；<< 左移翻倍；>> 右移减半
  6. 单片机控制引脚、配置寄存器全部靠位运算，不会改动其他引脚，精准控制单独某一位

三.复合赋值运算符

普通写法：a = a + 数字
意思是：拿a本身的值，加上一个数，算完之后，结果重新存回a里面。
复合赋值就是把这行代码简写，少敲重复的a，写单片机代码经常用。
复合赋值运算符:将运算和赋值合并为一步的简写方式
逐个讲常用6种，配简单例子
我们统一设初始值：int a = 5;

  1. 加法复合 +=
    简写 a += 3 等价完整写法 a = a + 3
    计算：5+3=8，最后a=8
  2. 减法复合 -=
    简写 a -= 2 等价 a = a - 2
    初始a=5，5-2=3，最后a=3
  3. 乘法复合 *=
    简写 a = 4 等价 a = a * 4
    5    4=20，a变成20
  4. 除法复合 /=
    简写 a /= 2 等价 a = a / 2
    5÷2=2（整数只留整数部分），a=2
  5. 取余复合 %=
    简写 a %= 2 等价 a = a % 2
    5除以2余1，a=1
  6. 位运算复合（单片机写寄存器天天用！重点）
  7. a |= (1<<2) 等价 a = a | (1<<2) 单独把第2位置1
  8. a &= ~(1<<3) 等价 a = a & ~(1<<3) 单独把第3位清零
  9. a ^= (1<<1) 等价 a = a ^ (1<<1) 翻转第1位电平
  10. a <<= 1 等价 a = a << 1 左移一位翻倍
  11. a >>= 1 等价 a = a >> 1 右移一位除以2

核心记忆口诀
符号= 等于 自己 符号 数字
举个万能模板：a OP= b ↔ a = a OP b
OP就是 + - * / % & | ^ << >> 任意运算符

易错点

  1. 复合运算符中间不能加空格，不能写成 a + = 3，正确 a +=3
  2. 等号永远在运算符右边，顺序别写反，没有 =+ 这种写法！

嵌入式实用例子（控制引脚）
unsigned int GPIOA = 0;
GPIOA |= (1<<15); // PA15引脚置高
GPIOA &= ~(1<<15); // PA15引脚清零
用复合写法代码更短，是写STM32寄存器标准写法。
