ROM的理解

RAM 与 ROM
总核心区分
ROM：断电数据不丢失，只读为主
RAM：断电全部清空，可读可写
在STM32里：
• ROM = FLASH（闪存）
• RAM = SRAM（静态内存）
一、ROM（Read-Only Memory 只读存储器）
1、核心特性

  1. 断电数据永久保存
  2. 原生定义：只能读取，不能随意改写；现代FLASH属于新型ROM，可以擦除再写入，但不能像内存一样随时随机改写
  3. 读取速度中等，写入/擦除速度很慢
  4. 按块（扇区）擦除，无法单独修改1个字节
    2、STM32中对应的硬件：片内FLASH
    3、存放什么数据（重点，写代码天天接触）
  5. 程序代码（.text段）
    你编译生成的程序，烧录到FLASH里。上电后CPU从FLASH读取指令运行
  6. 常量 const 修饰数据（.rodata）
    const uint8_t str[] = “hello”; // 存在FLASH(ROM)
    不加const的全局数组默认放到RAM
  7. 中断向量表
    4、局限
    优势：断电保存程序，上电不用重新下载
    缺点：
    • 不能实时频繁写入；
    • 改写前必须整页擦除；
    • 运行时不适合用来临时缓存变量
    5、生活类比
    书本（ROM）
    内容印刷好永久保存；你可以看书上文字（读），想要修改文字需要擦掉一整页重写，不能随手涂改单个字

二、RAM（Random Access Memory 随机存取存储器）
1、核心特性

  1. 断电瞬间所有数据全部消失
  2. 任意地址随时读、随时写，单字节自由修改，不需要擦除
  3. 读写速度远快于FLASH
  4. 只有芯片上电运行时才有效
    2、STM32对应的硬件：SRAM（静态随机存储器）
    3、存放哪些变量（C语言分区重点）
  5. 全局变量、静态局部变量(.data/.bss)
    uint8_t buf[100]; //全局数组 → SRAM
    static int a;
  6. 函数内部局部变量（栈Stack）
    void test(void){
    int temp; //栈内存，属于RAM
    }
  7. 动态内存分配 堆Heap（malloc）
  8. DMA搬运、串口接收缓存、临时运算缓冲区
    4、局限
    优势：读写极快，程序运行临时数据首选
    缺点：断电丢失；容量通常比FLASH小很多；一旦内存溢出程序死机
    生活类比
    草稿纸（RAM）
    写演算、临时数据随便涂改；一旦拿走电源（草稿纸撕碎），上面内容全部消失

三、表格直观对比
对比项目 ROM(STM32 FLASH) RAM(STM32 SRAM)
断电 数据保留 数据全部丢失
读写特性 可读；写入需要先擦除整页 随时随机读写，单字节修改
速度 读取较快，写入慢 高速读写
存放内容 程序代码、const常量 全局变量、局部变量、运行缓存
用途 长期存储固件、固定参数 程序运行临时数据交换
地址访问 上电持续读取，不适合频繁改写 程序运行全程频繁交互

四、结合最近学的DMA知识点串联（重中之重）
M2M：FLASH(ROM) → SRAM(RAM)
FLASH属于ROM，不能直接实时修改
如果你想运算一段常量数组，不能直接在FLASH运算
标准流程：DMA把FLASH里常量拷贝到SRAM，CPU在RAM里面修改、运算
M2P：SRAM(RAM) → USART外设
串口发送缓冲区必须放在RAM；DMA从SRAM取出数据送往串口
高频易错

  1. const数组放FLASH（ROM），不占用RAM；大量大数组建议加const节省内存
  2. 绝对不要在中断里往FLASH频繁写数据，擦写耗时会导致系统卡死
  3. RAM空间有限，定义超大局部数组容易栈溢出死机
    五、拓展
  4. 硬盘/U盘 = 类似ROM（持久存储）
  5. 电脑内存条 = RAM（断电清空）
    电脑流程类比单片机：
    系统文件存硬盘(ROM) → 开机加载到内存条(RAM) → CPU运行
    STM32流程：
    程序存FLASH(ROM) → 上电运行，变量在SRAM(RAM)
