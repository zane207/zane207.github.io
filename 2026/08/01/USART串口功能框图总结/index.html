USART串口功能框图总结

STM32 USART串口功能框图四大模块详解
野火课程把串口内部硬件划分为4大核心模块：“引脚、数据寄存器、控制器、波特率发生器”

一、引脚（硬件对外接口）

  1. 引脚英文与释义
  • TX：Transmit，发送引脚，串行数据输出
  • RX：Receive，接收引脚，串行数据输入
  • CK：Clock，同步模式时钟输出（异步串口一般不用）
  • nRTS：Request To Send，请求发送（硬件流控输出）
  • nCTS：Clear To Send，允许发送（硬件流控输入）
  1. 作用
    作为USART外设与外部电路交互的出入口
    发送时：内部并行数据转换成串行比特流，从TX引脚输出电平
    接收时：RX引脚采集外部电平信号，送入内部电路转换成并行数据
  2. 硬件要求：TX、RX需要配置为复用功能模式，开启对应GPIO时钟与USART外设时钟

二 、数据寄存器（数据缓冲区核心）
分为“发送通路”和“接收通路”，两套独立硬件
寄存器英文释义

  • TDR：Transmit Data Register，发送数据寄存器
  • RDR：Receive Data Register，接收数据寄存器
  1. 发送端：TDR（发送数据寄存器） + 发送移位寄存器
    CPU把要发送的字节写入TDR；硬件自动将TDR数据搬运到发送移位寄存器，逐位串行移出到TX引脚
    TDR为空时会置位TXE（发送寄存器空）标志，通知CPU可以继续填充下一组数据
  2. 接收端：RDR（接收数据寄存器） + 接收移位寄存器
    RX引脚收到串行比特，先进入接收移位寄存器；收满1帧完整数据后，自动并行存入RDR寄存器
    数据就绪后置位RXNE（接收寄存器非空）标志，通知CPU读取RDR
  3. 关键特点
    移位寄存器负责串并转换（并行 ↔ 串行）；
    TDR/RDR作为CPU和移位寄存器之间的缓冲，实现硬件持续收发。

三、控制器（控制逻辑、中断、状态管理）
框图中的发送控制、接收控制、中断单元统一归为控制器。
相关标识释义

  • 中断单元（Interrupt）：产生中断请求信号，送往NVIC
  • SR：Status Register，状态寄存器（存放TXE、RXNE、TC各类标志位）
  • CR：Control Register，控制寄存器（开启发送、接收、校验、模式选择）
  • TC：Transmission Complete，发送完成标志
    主要功能
  1. 帧时序控制
    严格按照串口协议，自动添加起始位、停止位、校验位，完成一帧数据封装/解析
  2. 状态标志管理
    生成TXE、RXNE、TC等状态位，CPU通过查询标志判断收发状态
  3. 中断触发控制
    满足条件时向NVIC发起中断请求（收到数据、发送完成等场景）
  4. 模式管理
    控制异步/同步模式、全双工、校验使能、停止位长度等通信参数

简单理解：控制器就是串口的“总指挥”，管理整套收发时序逻辑。

四、波特率发生器（USART_BRR寄存器）
英文释义

  • BRR：Baud Rate Register，波特率寄存器
  • fplck：外设输入时钟（来自APB时钟树）
  • USARTDIV：分频系数
    核心作用
    产生稳定的收发采样时钟，决定串口通信速率
    输入时钟来自APB时钟，经过BRR内部分频运算，输出标准采样时钟
    USARTDIV由BRR寄存器中的小数部分、整数部分共同计算得出
    重点知识点
  1. 收发双方波特率必须完全匹配，否则采样错位，数据乱码；
  2. 波特率发生器独立供给发送、接收电路时钟，保证发送、接收节拍同步；
  3. BRR寄存器用来配置分频系数，是初始化串口必不可少的一步
  4. 整体收发流程串联（方便理解框图）
  5. 发送流程：
    CPU写入数据 → TDR → 发送移位寄存器 → TX引脚输出（按照波特率时钟逐位移出）
  6. 接收流程：
    RX引脚采集电平 → 接收移位寄存器串转并 → 收满1帧存入RDR → 置位接收标志，通知CPU读取
  7. 四大模块协作关系：
    波特率发生器提供统一节拍时钟 → 控制器管控时序规则 → 数据寄存器完成串并转换缓冲 → 引脚实现对外信号传输
英文缩写 英文全称 中文含义
USART Universal Synchronous/Asynchronous Receiver/Transmitter 通用同步异步收发器
TX Transmit 发送
RX Receive 接收
TDR Transmit Data Register 发送数据寄存器
RDR Receive Data Register 接收数据寄存器
TXE Transmit Data Register Empty 发送寄存器空标志
RXNE Receive Data Register Not Empty 接收寄存器非空标志
TC Transmission Complete 发送完成标志
SR Status Register 状态寄存器
CR Control Register 控制寄存器
BRR Baud Rate Register 波特率寄存器
CK Clock 同步时钟
RTS Request To Send 请求发送（流控）
CTS Clear To Send 允许发送（流控）
