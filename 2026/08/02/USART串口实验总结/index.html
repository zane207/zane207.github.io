USART串口实验总结

第一、串口收发实验 标准6步初始化流程
1、 初始化串口GPIO引脚
核心知识点
USART的TX、RX引脚不是普通GPIO，需要配置为复用功能（AF）
用到结构体：GPIO_InitTypeDef
关键函数：GPIO_PinAFConfig()
流程：

  1. 开启GPIO端口时钟（RCC）
  2. 定义GPIO初始化结构体
  3. TX引脚：复用推挽输出
  4. RX引脚：复用浮空输入 / 上拉输入
  5. GPIO_Init()完成基础配置
  6. GPIO_PinAFConfig() 指定引脚映射到对应的串口复用功能编号
    重点：没有配置AF复用功能，串口无法正常收发数据！

2、初始化串口外设 USART
用到结构体：USART_InitTypeDef
内部配置项：

  • 波特率
  • 数据位长度（8bit）
  • 停止位数量
  • 校验位（无校验/奇/偶校验）
  • 硬件流控（初学关闭）
  • 模式：收发使能（Tx+Rx，全双工）
    调用函数：USART_Init()

3、中断配置（接收中断必备）

  1. 开启USART外设时钟
  2. 开启串口接收中断使能 USART_ITConfig()
  3. 配置NVIC：设置中断抢占优先级、子优先级，使能中断通道
    如果只做单纯发送、不需要接收，可以暂时跳过中断配置。

4、使能串口外设
USART_Cmd(USARTx, ENABLE);
所有参数配置完成后，最后打开串口总开关，外设正式开始工作。

5、编写发送函数、接收读取函数
发送函数逻辑
等待 TXE标志位，将数据写入DR寄存器，硬件自动串行发送。
接收读取逻辑
中断触发后，直接读取 USART_ReceiveData() 获取收到的字节。

6、编写中断服务函数
函数名固定，启动文件预先定义：USARTx_IRQHandler()
内部逻辑：

  1. 判断中断来源（接收中断标志 USART_IT_RXNE）
  2. 如果是接收中断，读取收到的数据
  3. 可把数据存入缓冲区，供主函数调用

第二、课件四大拓展问题细致解答
1、如何发送16位数据？
原理
标准串口一帧最多一次传输8bit（1字节），硬件原生不支持直接一次性发送16位
两种实现方案
方案1：拆分高低字节（最常用）
uint16_t data = 0x1234;
Send_Byte( data >> 8 ); // 先发高8位 0x12
Send_Byte( data & 0xFF );// 再发低8位 0x34
接收端按照同样顺序拼接两个字节，还原16位数据。
方案2：修改串口帧格式（极少使用）
配置USART为9位数据模式（包含校验位充当第9bit），上限仅9bit，依然达不到16bit。
结论：工程统一采用高低字节拆分传输。

2、如何发送一个数组？
循环调用单字节发送函数，遍历数组逐个发送。
示例代码：
void Send_Array(uint8_t *buf, uint16_t len)
{
uint16_t i;
for(i=0; i<len; i++)
{
Send_Byte(buf[i]);
}
}
调用：
uint8_t arr[] = {0x11,0x22,0x33};
Send_Array(arr, sizeof(arr));

3、如何使用printf()打印输出
底层原理
printf 标准库默认输出到电脑屏幕，我们需要重定向fputc函数，把printf输出的字符转发到串口发送函数。
核心重定向模板（F4标准库）：
int fputc(int ch, FILE *f)
{
USART_SendData(USART1, (uint8_t)ch);
while(USART_GetFlagStatus(USART1, USART_FLAG_TXE) == RESET);
return ch;
}
KEIL注意事项：
需要勾选：Use MicroLIB（微型库），否则部分版本重定向会失效。
重定向完成后，就可以直接使用：
printf(“测试数值 = %d\r\n”, 123);

4、电脑串口助手发送过来的数据是什么格式？
核心结论：
物理线路上永远传输二进制字节（0/1比特流），不存在十进制、十六进制区分！格式只由【串口助手显示模式】决定。

  1. 字符模式（ASCII模式）
    你发送 A → 线路传输字节 0x41
    单片机收到：0x41（ASCII编码）
  2. 十六进制模式（HEX发送）
    你输入 41，助手直接发送字节 0x41
    看起来结果一样，但逻辑不同：
    字符模式输入”41”，会发送两个字节 0x34、0x31（’4’和’1’的ASCII码）
    通俗区分
    • 十进制、十六进制：只是人类观察数字的书写形式
    • 线路、单片机寄存器里，只有原始8位二进制字节
    高频踩坑：
    很多新手混淆：串口助手发数字“10”
    字符模式：发送两个字节 ‘1’(0x31)、’0’(0x30)
    HEX模式：发送一个字节 0x10

补充串联总结
前面6步是串口底层硬件初始化标准流水线；后面4个问题是工程最常用的上层封装技巧。
学习顺序建议：
单字节收发 → 数组发送 → 16位数据分包传输 → printf重定向 → 电脑端收发格式区分。
