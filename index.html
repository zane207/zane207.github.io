手动搭建GPIO函数库函数雏形

一：外设寄存器结构体定义
核心思想：
在之前的课程中，操作一个GPIO引脚需要记住基地址和偏移地址（如 0x40021400+0x00），这非常容易出错。这节课引入了编程学习中结构体（struct），将属于同一个外设（如GPIOF）的所有寄存器打包在一起。通过指针强转，我们可以用 -> 语法直观地访问各个寄存器。

关键代码：
// 1. 定义GPIO外设的结构体，严格按照数据手册的寄存器顺序排列
typedef unsigened int uint32_t;
typedef unsigened short int uint16_t;
typedef struct
{
uint32_t MODER; // 模式寄存器 (偏移量: 0x00)
uint32_t OTYPER; // 输出类型寄存器 (偏移量: 0x04)
uint32_t OSPEEDR; // 输出速度寄存器 (偏移量: 0x08)
uint32_t PUPDR; // 上下拉寄存器 (偏移量: 0x0C)
uint32_t IDR; // 输入数据寄存器 (偏移量: 0x10)
uint32_t ODR; // 输出数据寄存器 (偏移量: 0x14)
uint16_t BSRRL/H; // 置位/复位寄存器 (偏移量: 0x18)
uint32_t LCKR; // 配置锁定寄存器 (偏移量: 0x1C)
uint32_t AFRL/H; // 复用低/高功能寄存器 (偏移量: 0x20, 0x24)
} GPIO_TypeDef;

// 2. 利用宏定义，将结构体指针绑定到具体的硬件基地址上
define GPIOF_BASE (( unsigned int )0x40021400)
define GPIOF (GPIO_TypeDef *)GPIOF_BASE

二：编写端口复位和置位函数
核心思想：
封装好结构体后，接下来把常用的操作（如点亮、熄灭LED）封装成函数。这样在 main.c 中调用时，代码的可读性会大幅提升，不再需要写冗长的位操作（&= ~ 或 |=）。

关键代码：
// 置位函数（输出高电平）
void GPIO_SetBits(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin)
{
GPIOx->BSRRL = GPIO_Pin; // 向低16位写1，对应引脚输出高电平
}

// 复位函数（输出低电平）
void GPIO_ResetBits(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin)
{
GPIOx->BSRRH = GPIO_Pin; // 向高16位写1，对应引脚输出低电平
}
// 在main函数中调用变得非常简洁：
// GPIO_SetBits(GPIOF, GPIO_Pin_6);

三：定义外设初始化结构体和编写外设初始化函数
核心思想：
为了避免初始化函数出现“参数爆炸”（即函数括号里需要传入十几个参数），引入了初始化配置结构体。将引脚、模式、速度等配置打包，通过指针一次性传给初始化函数。

关键代码：
// 1. 定义GPIO初始化配置结构体
typedef struct
{
GPIOMode_TypeDef MODER;
uint32_t 0TYPER;
uint32_t 0SPEED;
uint32_t PUPDR;
} GPIO_InitTypeDef;

// 2. 编写统一的初始化函数
void GPIO_Init(GPIO_TypeDef* GPIOx, GPIO_InitTypeDef* GPIO_InitStruct) {
// 开启对应GPIO端口的时钟（以GPIOF为例，实际操作需根据传入的GPIOx动态判断）
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOFEN; 

// 根据结构体中的配置，配置MODER、OSPEEDR、PUPDR等寄存器
// 这里省略了具体的位运算逻辑，核心思想是通过指针读取结构体的值并写入寄存器
GPIOx->MODER &= ~(0x03 GPIO_Pin);
GPIOx->MODER |= (GPIO_InitStruct->GPIO_Mode GPIO_Pin);
// ... 其他寄存器的配置

}

// 3. 在main函数中的标准使用流程：
GPIO_InitTypeDef GPIO_InitStructure;
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_6;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_OUT;
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_InitStructure.GPIO_PuPd = GPIO_PuPd_UP;
GPIO_Init(GPIOF, &GPIO_InitStructure);

总结:嵌入式软件架构的演进过程：绝对地址访问 -> 结构体映射 -> 函数封装 -> 结构体传参

C语言关于scanf,typedef的笔记

#关于scanf,typedef

一.scanf 是干嘛的？

scanf = 让程序等待你从键盘打字输入数字/文字，把你敲的内容存到变量里。
没有它程序只会自己跑，有了它你能手动给程序填数据。

类比：
程序是收银机，printf 是屏幕提示“请输入金额”，scanf 就是读取你按键盘输的数字。

固定格式（死记就行）0=
scanf(“格式符号”, &变量名);
两个必懂关键点：

二.格式符号：告诉程序你要输入什么类型数据

%d = 整数（年龄、数字）

%f = 小数（身高、价格）

%s = 一串文字（姓名、单词，不带空格）

& 取地址符号：除了数组，普通变量前面必须加！
大白话：& 就是告诉程序“把你输入的东西放到这个变量的内存盒子里”

最简单完整例子（输入年龄）
#include <stdio.h>
int main()
{
int age; // 造一个盒子age，装整数
printf(“请输入你的年龄：”); // 提示文字
scanf(“%d”, &age); // 等待键盘输入数字，存进age
printf(“你今年%d岁”, age); // 打印你输入的数字
return 0;
}
运行流程：

  1. 屏幕弹出：请输入你的年龄：

  2. 你键盘敲 18，按回车

  3. 18 自动装进 age 变量

  4. 屏幕输出：你今年18岁

分类型举例，一看就会

输入整数 %d
int num;
scanf(“%d”, &num);
输入小数 %f
float height;
scanf(“%f”, &height);
输入名字（字符数组，不用加&！重点）

之前结构体的 char name[20] 就是数组，数组名字本身自带地址，不许写&
char name[20];
scanf(“%s”, name); // 没有&！
三.初学者最容易踩的3个坑

坑1：普通变量忘记写 &

错误：scanf(“%d”, age);
正确：scanf(“%d”, &age);
不写&程序会直接崩溃乱码。

坑2：给文字数组多加了&

错误：scanf(“%s”, &name);
正确：scanf(“%s”, name);
数组自带地址，加&反而报错。

坑3：输入带空格的文字读不全

scanf(“%s”) 遇到空格就停止读取
比如你输入 zheng jiawei，它只会存 zhang，后面文字直接丢掉。

四.typedef到底是干嘛的？

直译：类型重命名
大白话：给复杂的数据类型起一个简短好写的外号，少打字、不容易写错。

对比不用typedef 和 用typedef 的区别（拿结构体举例）

1.不使用typedef（原生写法，每次都要写struct）
struct Student{
char name[20];
int age;
};
// 创建变量必须完整写 struct Student
struct Student s1;
struct Student s2;
缺点：每次新建学生变量，都要带上 struct 四个字，代码长、麻烦。

2.使用typedef（起外号 Stu）
// typedef + 原类型 + 新外号
typedef struct Student{
char name[20];
int age;
} Stu;
// 直接用外号创建变量，不用写struct
Stu s1;
Stu s2;
拆解这句：
typedef struct Student = 原来完整的类型名
Stu = 我们给它起的简短外号

3.通用万能公式（所有类型都能用typedef）
typedef 原来的类型 新名字;
示例1：给int起外号（简单类型也能用）
typedef int Num;
Num a = 18; // 等价于 int a = 18;
示例2：给float起外号
typedef float Score;
Score math = 95.5;
4.初学者最容易记混的关键点

5.typedef 不会创造新类型，只是换个名字，底层还是原来的struct/int/float；

62.结构体搭配typedef是写代码最常用场景，专门简化变量定义；

7.顺序不能写反：typedef 原名 外号，不能反过来。

五.scanf与typedef和之前结构体结合的完整实操代码
#include <stdio.h>
#include <string.h>

typedef struct Student{
char name[20];
int age;
} Stu;

int main()
{
Stu s1;
// 输入姓名
printf(“请输入学生姓名：”);
scanf(“%s”, s1.name);
// 输入年龄
printf(“请输入学生年龄：”);
scanf(“%d”, &s1.age);
// 打印读取到的数据
printf(“学生：%s，年龄：%d”, s1.name, s1.age);
return 0;
}
运行后你手动输入名字、年龄，程序就能读取并存进结构体里。

极简总结

  1. scanf 用来读取键盘输入；

  2. 数字/小数变量前面必须加 &；

  3. char 文字数组不用加 &；

  4. %d存整数，%f存小数，%s存文字。

C语言结构体笔记

#关于结构体
一、结构体是干嘛的？

普通变量只能存单个数据：int年龄、char姓名、float分数。
结构体 = 自己造一个复合盒子，把同一个人的多种信息打包放一起。
比如学生：姓名、年龄、分数、班级，全部塞进一个结构体。

二、结构体的定义

struct:释义： （名词）结构；结构体；构架；组织；体系 （动词）使形成体系；
struct结构体类型名
{
数据类型 成员名;
数据类型 成员名;
……
};
定义结构体的方法
1.先定义结构体类型，再定义结构体变量 （可定义局部或全局的结构体变量）
例：
struct Student
{
char name[20]; //姓名
int age; //年龄
float score; //成绩
}；

struct Student s1,s2;（可定义多个变量）

2.定义结构体的同时，定义结构体的变量 （可定义全局的结构体变量）
例：
struct Student
{
char name[20]; //姓名
int age; //年龄
float score; //成绩
}s3,s4;（可定义多个变量）

3.定义无名结构体类型变量 （可定义全局的结构体变量）
例：
struct （这里没有Student了）
{
char name[20]; //姓名
int age; //年龄
float score; //成绩
}s5,s6;（可定义多个变量）

三.结构体变量的初始化与赋值
struct Student
{
char name[20]; //姓名
int age; //年龄
float score; //成绩
}；
struct Student s1 = { “Jane”,20,95.5};
struct Student s2 = { “Jack,21,(没有的就显示为0)};

struct Student
{
char name[20]; //姓名
int age; //年龄
float score; //成绩
}s3 = {“Mike”,22,88};

四.两个结构体变量之间可以相互赋值
struct Student s1 = { “Jane”,20,95.5};
struct Student s2 = { “Jack,21};
s2=s1
则struct Student s2 = { “Jane”,20,95.5};
struct Student s2=s1和上述一样

五.结构体成员的访问
#include<stdio.h>
