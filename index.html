C语言结构体笔记

#关于结构体
一、结构体是干嘛的？

普通变量只能存单个数据：int年龄、char姓名、float分数。
结构体 = 自己造一个复合盒子，把同一个人的多种信息打包放一起。
比如学生：姓名、年龄、分数、班级，全部塞进一个结构体。

二、结构体的定义

struct:释义： （名词）结构；结构体；构架；组织；体系 （动词）使形成体系；
struct结构体类型名
{
数据类型 成员名;
数据类型 成员名;
……
};
定义结构体的方法
1.先定义结构体类型，再定义结构体变量 （可定义局部或全局的结构体变量）
例：
struct Student
{
char name[20]; //姓名
int age; //年龄
float score; //成绩
}；

struct Student s1,s2;（可定义多个变量）

2.定义结构体的同时，定义结构体的变量 （可定义全局的结构体变量）
例：
struct Student
{
char name[20]; //姓名
int age; //年龄
float score; //成绩
}s3,s4;（可定义多个变量）

3.定义无名结构体类型变量 （可定义全局的结构体变量）
例：
struct （这里没有Student了）
{
char name[20]; //姓名
int age; //年龄
float score; //成绩
}s5,s6;（可定义多个变量）

三.结构体变量的初始化与赋值
struct Student
{
char name[20]; //姓名
int age; //年龄
float score; //成绩
}；
struct Student s1 = { “Jane”,20,95.5};
struct Student s2 = { “Jack,21,(没有的就显示为0)};

struct Student
{
char name[20]; //姓名
int age; //年龄
float score; //成绩
}s3 = {“Mike”,22,88};

四.两个结构体变量之间可以相互赋值
struct Student s1 = { “Jane”,20,95.5};
struct Student s2 = { “Jack,21};
s2=s1
则struct Student s2 = { “Jane”,20,95.5};
struct Student s2=s1和上述一样
